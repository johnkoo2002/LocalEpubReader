# 页间 · LocalEpubReader

Android 本地阅读器，支持 EPUB、TXT 和未加密的 MOBI 6/7。纯 KF8/AZW3 与 DRM 暂不支持。

[下载最新版 APK](https://github.com/johnkoo2002/LocalEpubReader/releases/latest/download/LocalEpubReader.apk)

首次安装请按手机系统提示允许浏览器安装应用。后续点击应用书架右上角的“应用更新”，下载后覆盖安装即可保留书籍、进度和书签。

阅读与格式转换均在手机本地完成，阅读器不申请联网权限。浏览器负责从 GitHub 下载更新。本仓库仅分发安装包和校验信息，不包含私人书籍或签名密钥。
